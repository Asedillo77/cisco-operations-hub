# Security Policy

Please do not open a public issue containing credentials, authentication material, internal device
inventory, private addresses, topology output, routing information, or production reports.

The included examples use fictional hostnames and addresses from `192.0.2.0/24`, which is reserved
for documentation. Populated credential files and generated runtime outputs are excluded from Git.

Before sharing any report created from a real environment, review its hostnames, management
addresses, neighbor details, route evidence, hardware identifiers, timestamps, and raw command
output. Prefer a restricted report link over a public attachment.

Security concerns can be reported privately through the repository owner's GitHub profile.
